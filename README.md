# 🍽️ Restaurant Mobile App – UI/UX Design  
A modern and user-friendly restaurant mobile application designed to improve food ordering, table booking, browsing menus, and managing user interactions.  
This project focuses on creating an intuitive, clean, and seamless experience for customers using the restaurant's digital app.

## 🚀 Project Overview  
This restaurant app design solves common pain points such as:
- Slow food ordering experience  
- Confusing menu layouts  
- Difficulty in customizing dishes  
- Lack of simple table reservation flow  
- Poor user engagement  

The redesigned interface provides a **smooth, fast, and visually appealing** flow for ordering food and exploring dishes.

## 🎯 Core Features Designed  

### ✔ 1. **Onboarding Screens**  
- Highlights restaurant specialties  
- Clean food images  
- Brand colors + typography  

### ✔ 2. **Home Screen**  
- Search bar  
- Popular dishes  
- Recommended items  
- Quick categories (Pizza, Biryani, Desserts, Drinks, etc.)

### ✔ 3. **Menu Screen**  
- Filter by category  
- Price sorting  
- High-quality food images  
- Ingredients list  

### ✔ 4. **Food Details Screen**  
- Add/Remove addons  
- Size selection  
- Special instructions  
- Nutrition info  

### ✔ 5. **Cart & Checkout**  
- Edit quantities  
- Add coupon  
- Payment summary  
- Delivery or Pickup selection   

### ✔ 7. **Order Tracking Screen**  
- Order timeline  
- Live driver tracking  
- Estimated delivery time
